# Fine Laban | Online Storefront & Direct Ordering System

A lightweight, responsive web platform designed for Fine Laban, a specialty Middle Eastern dessert brand based in Trichy, India.

🔗 **Live Demo:** [View Live Site](https://Neels-the-pirate.github.io/<repo-name>/)

---

## 🌟 Features
* **Interactive Menu System:** Browse items across multiple categories with a dynamic display-toggle for extended offerings.
* **WhatsApp Commerce Integration:** Instant order processing that calculates cart totals and generates formatted order dispatches straight to the vendor via WhatsApp API.
* **Responsive UI/UX:** Built with mobile-first layouts, smooth scroll mechanics, and floating keyframe CSS animations.
* **Customer Feedback Engine:** Integrated modal form with honeypot anti-spam routing via FormSubmit API.
* **SEO Ready:** Complete with metadata, structured sitemap, and robots.txt.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Frameworks & Libraries:** Bootstrap 4.5.2, Font Awesome 6
* **Hosting & CDN:** GitHub Pages, Cloudinary (Asset Optimization)
* **Integrations:** WhatsApp Click-to-Chat API, FormSubmit API
